# Netflix Data Analysis Project

## 📌 Overview
This project presents an end-to-end data analysis of Netflix content using Python, SQL, and Power BI. The objective is to explore and extract meaningful insights from the dataset, focusing on content trends, genre distribution, and growth patterns over time.

## 🛠 Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)  
- SQL  
- Power BI  

## 🔍 Project Workflow
- Performed data cleaning and preprocessing using Python by handling missing values, duplicates, and inconsistencies.  
- Conducted exploratory data analysis (EDA) to understand trends in content type, release years, ratings, and genres.  
- Wrote SQL queries with joins, aggregations, and filtering to derive key insights from the dataset.  
- Developed an interactive Power BI dashboard to visualize important metrics and trends.

## 📊 Key Insights
- Rapid growth in content addition observed after 2015.  
- Movies constitute a larger portion of the platform compared to TV shows.  
- Drama and international content are among the most popular genres.  
- The United States produces the highest number of titles.
