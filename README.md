Netflix Data Analysis Project
📌 Overview

This project presents an end-to-end data analysis of Netflix content using Python, SQL, and Power BI. The goal is to explore the dataset and extract meaningful insights related to content trends, genre distribution, and growth over time.

🛠 Tools & Technologies
Python (Pandas, NumPy, Matplotlib, Seaborn)
SQL
Power BI
🔍 Project Workflow
Performed data cleaning and preprocessing using Python by handling missing values, duplicates, and inconsistencies.
Conducted exploratory data analysis (EDA) to identify trends in content type, release years, ratings, and genres.
Wrote SQL queries using joins, aggregations, and filtering to extract key insights.
Built an interactive Power BI dashboard to visualize important metrics and trends.
📊 Key Insights
Rapid growth in content after 2015.
Movies dominate compared to TV shows.
Drama and international genres are most popular.
United States produces the highest number of titles.
